# Терминальный Понг (C++)

Классическая игра Понг, работающая прямо в терминале.
Быстрый ввод, плавный игровой цикл, ускорение мяча, механика закручивания и простой ИИ-противник.

---

## 🎮 Возможности

* Ввод с клавиатуры в реальном времени (нажатие Enter не требуется)
* Игровой цикл с частотой около 60 FPS
* Постепенное увеличение скорости мяча
* Закручивание мяча в зависимости от точки удара о ракетку
* Простой ИИ для Игрока 2 (можно заменить ручным управлением)
* Автоматическое восстановление состояния терминала при выходе
* Работает в стандартных POSIX-терминалах

---

## ⌨️ Управление

**Игрок 1**

* `w` — движение вверх
* `s` — движение вниз

**Игрок 2**

* `o` — движение вверх
* `l` — движение вниз

**Общие**

* `q` — выход из игры

---

## 🛠️ Сборка и запуск

### Linux / macOS / WSL

```bash
g++ pong.cpp -std=c++17 -O2 -Wall -Wextra -o pong
./pong
```

> Требуется терминал с поддержкой управляющих последовательностей ANSI и `termios`.

## ⚙️ Технические примечания

* Использование неблокирующего ввода с помощью `fcntl`.
* Управление сырым режимом терминала с использованием концепции RAII.
* Контроль времени кадров с помощью `std::chrono`.
* Отрисовка с использованием ANSI escape-последовательностей.
